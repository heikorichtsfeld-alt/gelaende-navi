# Gelände-Navi Winterhafen

Navigation am Werftgelände per QR-Code und GPS. Die ganze App ist die Datei `index.html`
(Karte, Routen, GPS, QR-Schilder), sie läuft ohne Server über GitHub Pages.

## Adressen
- Start: `/#` · Standort A: `/#a` · B → Ausfahrt: `/#b-exit` · C → Ausfahrt: `/#c-exit`
- Direkt: `/#a-b`, `/#a-c`
- QR-Schilder erzeugen: `/#qr` · GPS-Punkte prüfen/neu einmessen: `/#einmessen`

## GPS-Punkte ändern
In `index.html` den Abschnitt `SITE_POINTS` anpassen (Breite, Länge).
